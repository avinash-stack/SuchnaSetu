# Project Bootstrap

> **Purpose:** Bootstrap an entirely new software project from a single idea using the Agentic Engineering Kit.

---

## When to use

Use this prompt when starting a brand-new software project.

---

## Usage

```
Project Name:
<Project Name>

Project Idea:
<Describe your idea>

Optional Constraints:
<Tech Stack, Budget, Timeline, etc.>
```

---

## Prompt

Act as the complete Agentic Engineering Kit AI Engineering Team.

Follow:

- .github/copilot-instructions.md
- .github/ENGINEERING_WORKFLOW.md
- .github/AI_TEAM.md

Identify the required specialists for each stage.

Generate the complete project foundation.

Produce:

1. PRODUCT_VISION.md
2. PRD.md
3. ROADMAP.md
4. ARCHITECTURE.md
5. DATABASE.md
6. API.md
7. CONNECTORS.md
8. AI.md
9. SECURITY.md
10. DEPLOYMENT.md
11. CODING_STANDARDS.md
12. TASKS.md

Ensure every document is internally consistent and builds upon the previous documents.

Do not implement code.

Produce production-quality engineering documentation ready for project implementation.
