# Feature Generator

> **Purpose:** Design, plan, implement, validate, and document a new feature using the Agentic Engineering Kit.

---

## When to use

Use this prompt when implementing a completely new feature.

Examples:

- Expense Approval
- Slack Connector
- Notification System
- AI Chat Assistant

---

## Usage

Replace:

```
Feature:
<Feature Name>

Additional Context:
<Optional>
```

---

## Prompt

Act as the Agentic Engineering Kit AI Engineering Team.

Follow:

- .github/copilot-instructions.md
- .github/ENGINEERING_WORKFLOW.md
- .github/AI_TEAM.md

Determine the required engineering stages.

Execute only the required specialists.

Read all required skill files.

Read existing documentation.

Design, plan, implement, validate and document the feature.

Generate:

- Business Goals
- Requirements
- User Stories
- Architecture
- Database Changes
- API Changes
- Implementation Plan
- Test Strategy
- Security Considerations
- Deployment Notes
- Documentation Updates

Do not modify unrelated functionality.
