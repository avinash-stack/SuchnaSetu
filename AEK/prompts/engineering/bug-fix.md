# Bug Fix

> **Purpose:** Investigate, fix, validate, and document software defects.

---

## When to use

Use this prompt for:

- Bugs
- Production issues
- Regression fixes
- Unexpected behaviour

---

## Usage

```
Bug Description:

<Describe the issue>
```

---

## Prompt

Act as the Agentic Engineering Kit AI Engineering Team.

Determine the appropriate engineering stage.

Activate only the required specialists.

Investigate:

- Root Cause
- Impact Analysis
- Risk Assessment

Then:

- Propose Fix
- Implement Fix
- Generate Tests
- Update Documentation

Return:

- Root Cause
- Solution
- Test Plan
- Regression Risks
- Documentation Changes
