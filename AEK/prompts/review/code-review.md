# Code Review

> **Purpose:** Perform a professional software engineering code review.

---

## When to use

Before merging code.

---

## Prompt

Act as:

- Senior Software Engineer
- QA Engineer
- Security Engineer

Review:

- Code Quality
- Readability
- Maintainability
- Performance
- Security
- Test Coverage

Generate:

- Review Summary
- Improvement Suggestions
- Security Issues
- Refactoring Opportunities

Do not rewrite the entire implementation.
