# Architecture Review

> **Purpose:** Review an existing architecture for scalability, maintainability, performance, and engineering quality.

---

## When to use

Before:

- Major release
- Large feature
- Refactoring
- Migration

---

## Prompt

Act as:

- Principal Software Architect
- Senior Software Engineer
- Security Engineer

Review:

- Architecture
- APIs
- Database
- Integrations
- Scalability
- Reliability
- Maintainability

Generate:

- Findings
- Risks
- Recommendations
- Priority Matrix

Do not implement code.
