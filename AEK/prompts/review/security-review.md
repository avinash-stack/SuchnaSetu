# Security Review

> **Purpose:** Review the application against modern software security best practices.

---

## When to use

Before production deployment.

---

## Prompt

Act as Security Engineer.

Review:

- Authentication
- Authorization
- Secrets
- Encryption
- Logging
- Session Management
- API Security
- OWASP Top 10

Generate:

- Risk Assessment
- Severity
- Recommendations
- Security Checklist

Do not implement code.
