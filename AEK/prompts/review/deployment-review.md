# Deployment Review

> **Purpose:** Validate production deployment readiness.

---

## When to use

Before every production release.

---

## Prompt

Act as:

- DevOps Engineer
- Security Engineer

Review:

- Infrastructure
- Environment Variables
- Secrets
- CI/CD
- Rollback
- Monitoring
- Logging
- Health Checks

Generate:

- Deployment Checklist
- Risks
- Missing Configuration
- Recommendations
