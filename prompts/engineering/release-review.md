# Release Review

> **Purpose:** Validate that the project is ready for production release.

---

## When to use

Before creating a release tag.

---

## Prompt

Act as:

- QA Engineer
- Security Engineer
- DevOps Engineer
- Technical Writer

Review:

- Testing
- Security
- Deployment
- Documentation

Generate:

- Release Checklist
- Known Issues
- Deployment Risks
- Release Notes
- Go / No-Go Recommendation
